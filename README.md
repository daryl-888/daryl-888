## What I'm building and exploring
- **GPU performance:** CUDA kernels and GPU benchmarking — from microbenchmarks on an RTX 4070 Super to video-LLM inference evaluation on a GPU cluster.
- **Processor design:** RV32I datapaths, five-stage pipelines, forwarding, stalls, and control flow, with a growing focus on verification and FPGA implementation.
- **Systems fundamentals:** C++ emulation, instruction decoding, memory, and the details that connect software behavior to a machine.
- **Parallel computing education:** Hands-on learning materials that help students move from Linux and SSH to CUDA programming.

## Selected projects
| Project | What to explore |
| --- | --- |
| **[CUDA Kernels](https://github.com/daryl-888/cuda-kernels)** | CUDA implementations of vector addition, grayscale conversion, image blur, and matrix multiplication exercises. My foundation for studying parallel execution and memory access. |
| **[Ada GPU Microbenchmarks](https://github.com/daryl-888/ada-microbench)** | A benchmarking project characterizing the NVIDIA Ada Lovelace architecture on an RTX 4070 Super, with CUDA kernels and profiling scripts for memory coalescing and occupancy/ILP experiments. |

| **[CHIP-8 Emulator](https://github.com/daryl-888/DD-Emulated)** | A C++/SDL2 emulator with opcode execution, display rendering, keyboard input, ROM loading, and timers. A practical exploration of how an instruction set becomes a running system. |
| **[HuPulse](https://github.com/daryl-888/HuPulse)** | Research code for PPG-based blood pressure estimation, exploring state-space models and demographic conditioning, with training and evaluation workflows for an HPC cluster. |
